# Smart Mobility & Ride Analytics

## Overview

This project analyzes ride-hailing data using Python, probability,
descriptive statistics, correlation, outlier detection, and
hypothesis testing.

## Objective

The objective is to apply mathematical and statistical concepts
to a ride-hailing dataset and derive meaningful analytical insights.

## Dataset

The project uses a synthetic ride-analysis dataset containing
120 ride records.

The dataset includes information such as:

- Trip distance
- Fare amount
- Ride category
- Surge pricing
- Customer rating
- Peak-hour status
- Revenue
- Ride demand
- Wait time
- Driver rating
- Cancellation rate

## Technologies

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- Google Colab

## Analysis Performed

- Data preparation and cleaning
- Descriptive statistics
- Probability analysis
- Correlation and covariance
- Outlier detection
- Data visualization
- T-Test
- Chi-Square Test
- ANOVA
- Business insights

## Project Files

- `Smart_Mobility_Ride_Analytics.ipynb` — Main analysis notebook
- `Trip_Analysis.csv` — Dataset used for analysis
- `README.md` — Project documentation

## How to Run

The notebook can be opened and executed using Google Colab.

1. Open the notebook.
2. Upload `Trip_Analysis.csv` to the Colab session.
3. Run the notebook cells from top to bottom.

## Conclusion

The project demonstrates the application of Python-based
mathematical and statistical techniques to analyze ride-hailing
data and identify useful patterns and relationships.
